# zn-learn

一个持续积累的个人技术学习仓库，记录从前端基础到全栈工程实践的学习过程、可运行示例、问题复盘与技术笔记。

## 内容范围

- **基础与语言**：JavaScript、TypeScript、算法、C/C++、Go、Rust、Shell 等；
- **前端与浏览器**：HTML/CSS、React、Vue、浏览器 API、微前端、性能优化与 WASM；
- **工程化**：Babel、Vite、Rollup、Monorepo、提交规范与测试；
- **服务端与基础设施**：Node.js、NestJS、数据库、Docker、Nginx；
- **AI 与低代码**：Prompt、Agent/工作流抽象、AI 应用实验、表达式沙箱；
- **个人项目与技术笔记**：可运行 demo、源码阅读记录、踩坑复盘与技术决策。

## 仓库原则

- 以**可验证的学习输出**为主：能运行的 Demo、清晰的注释、可复现的问题与结论；
- 学习类笔记和小型实验按技术主题组织；`WebProjects/` 仅收录相对完整的个人 demo 项目；
- 文档与代码注释优先使用中文；
- 内容会持续调整，不把根目录 README 当作目录索引维护，具体内容请直接浏览各主题目录。

如果这些笔记或代码对你有帮助，欢迎 Star、Issue 或交流讨论，English OK。
