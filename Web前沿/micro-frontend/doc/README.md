# 微前端知识体系

## 一、什么是微前端

微前端（Micro Frontends）是一种将前端应用拆分为多个**独立开发、独立部署、独立运行**的小型应用，再通过一个主应用（基座）将它们组合在一起的架构模式。它借鉴了微服务的思想，解决了巨石前端应用的维护难题。

## 二、核心价值

| 维度             | 说明                                               |
| ---------------- | -------------------------------------------------- |
| **技术栈无关**   | 子应用可以使用不同的框架（React、Vue、Angular 等） |
| **独立开发部署** | 各团队独立开发、测试、部署，互不影响               |
| **增量升级**     | 可以逐步迁移老项目，不需要一次性重写               |
| **故障隔离**     | 单个子应用崩溃不影响其他子应用                     |

## 三、常见实现方案对比

| 方案                  | 原理                                 | 代表                         |
| --------------------- | ------------------------------------ | ---------------------------- |
| **路由分发**          | Nginx 按路由转发到不同应用           | 最简单，但体验差（页面刷新） |
| **iframe**            | 每个子应用一个 iframe                | 天然隔离，但通信困难、体验差 |
| **JS Entry**          | 加载子应用的 JS bundle 执行          | single-spa                   |
| **HTML Entry**        | 加载子应用的 HTML，解析其中的 JS/CSS | qiankun                      |
| **Web Components**    | 基于 Shadow DOM 封装子应用           | micro-app                    |
| **Module Federation** | Webpack 5 模块联邦，运行时共享模块   | Webpack 5                    |
